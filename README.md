# 水下考古潜次封存与标记复核台

直接打开 `index.html` 使用（无需构建，file:// 可用）。数据保存在浏览器 localStorage，刷新后筛选、时间线与导出保持一致。

## 分层实现

- `js/rules.js` —— 准入规则层：纯函数，不触碰 DOM 与存储。潜次双人绑定与持证深度、计划深度校验、标记完整性与编号唯一性、封存/复核准入判定。
- `js/store.js` —— 数据保存层：localStorage 持久化；所有写操作经互斥锁串行化（优先 Web Locks 跨标签页互斥，退化为页内队列），锁内重读最新状态再判定，保证并发提交只成功一次。
- `js/ui.js` —— 页面交互层：渲染与事件。展示与导出一律取已确认值，待复核内容以徽标和 diff 标出。

## 业务规则

- 每个潜次绑定两名**不同**潜水员，潜次持证深度取两人持证深度的较低值；**计划深度超限不得开始**。
- 潜次内标记**编号唯一**；**深度、朝向、保存状态缺一项不能转待封存**（待封存中若被改缺，自动退回进行中）。
- 封存后须**由另一人复核**；**确认前页面与导出仍显示原值**，更正以"待复核"暂存。
- 已确认潜次**新增或更正会回到待复核**，再次复核确认后生效。
- **重复封存沿用首次结果**（封存人/时间/快照不变）；**并发提交只成功一次**。
