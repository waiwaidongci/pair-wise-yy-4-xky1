# 潜次封存与标记复核台

在原“水下考古潜水记录”平面图标记工具上升级而来。直接打开 `index.html` 即可使用
（纯前端，数据保存在浏览器 `localStorage`；旧版 `zfl30Marks` 数据首次打开时自动迁移）。

## 业务规则

- **准入**：每个潜次绑定两名**不同**潜水员（各持证书最大深度），潜次持证上限取两人较浅值；
  计划深度超过上限时潜次**不得开始**（开始后持证上限固化，绑定与计划深度不可再改）。
- **封存**：潜次内标记编号必须唯一；**深度、朝向、保存状态**缺任一项不能封存。
- **复核**：封存后进入“待复核”，由**封存人之外的另一名绑定潜水员**确认；
  确认前台面始终显示**封存原值**（已复核后再更正的，显示上一次确认值）。
- **再更正**：封存/复核后新增、更正、删除标记，潜次自动回到“待复核”；
  首次封存快照永不改变——**重复封存沿用首次结果**。
- **并发**：封存、复核请求在保存层串行化并做在途拦截，**并发双提交只成功一次**。

潜次状态：计划中 → 进行中 → 待复核 ⇄ 已复核（更正后回到待复核）。

## 分层结构

| 层 | 文件 | 职责 |
 | --- | --- | --- |
 | 准入规则层 | `js/rules.js` | 纯函数式业务规则：准入、编号唯一/必填、封存快照、复核状态机；无 DOM、无存储，可在 Node 直接测试 |
 | 数据保存层 | `js/store.js` | `localStorage` 版本化读写、旧数据迁移、写事务串行队列与并发去重、订阅通知、种子数据 |
 | 页面交互层 | `js/app.js` + `index.html` | 平面图标记、表单、筛选、时间线、导出；所有判定调规则层，所有读写走保存层 |

筛选条件（类型/范围/列表-时间线视图）和当前操作人随偏好持久化，**刷新后筛选、
时间线与导出结果保持一致**；导出 JSON 包含潜水员、潜次（含事件流、封存/复核快照、
台面显示值 `displayMarks` 与待复核改动 `pendingMarkIds`）。

## 测试

```bash
node --test test/        # 规则层 + 保存层 9 项用例（含并发只成功一次、迁移、持久化）
node test/smoke.js       # 用最小 DOM 垫片跑真实页面脚本路径的端到端冒烟
```

覆盖：持证上限/超限拦截、编号唯一与三项必填、封存原值显示、另一人复核、
更正回到待复核、重复封存沿用首次结果、并发只成功一次、旧数据迁移、刷新一致性。
